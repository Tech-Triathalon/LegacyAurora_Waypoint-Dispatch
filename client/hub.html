Portals

Offline-first, all four roles. Every portal is an installable PWA: pages and app code are precached, API reads fall back to last-known snapshots when the network drops, and writes (orders, allocations, load events, shortage flags, receipts, PODs) queue locally with idempotency keys and replay automatically when the connection returns — deduped server-side, never double-applied. Live event stream (/api/stream) keeps every role current while online.
